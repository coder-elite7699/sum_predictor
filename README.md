# Sum Predictor

### About the project
This is project predicts the sum of two given numbers. It employes Machine Learning Model.It uses Linear Regression Model to predict the sum.

### How data was gathered?
2000 numbers were generated using pytjon's [random](https://docs.python.org/3/library/random.html) module. Feeded in a csv file having 3 columns input1, input2, sum.
Each input have 1000 entries(numbers).

### Tech Stack used
1. Pandas
2. Numpy
3. Flask
4. HTML
5. Matplotlib
6. Linear Regression
